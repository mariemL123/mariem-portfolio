# Mariem's Developer Portfolio

A responsive portfolio built with React, Vite and CSS to present Python, applied AI, backend and frontend interests. Project status is described transparently; learning goals are not presented as production experience.

## Run locally

Requirements: Node.js 22+ and npm.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and deploys the site on pushes to `main`. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. Then check the **Actions** tab for the deployment status.

Expected project-site URL: `https://mariemL123.github.io/mariem-portfolio/`.

## Before sharing

- Confirm project descriptions and current statuses.
- Keep credentials, `.env` files, private datasets and database files out of this public repository.
- FocusBoard is private, so its source is not publicly accessible from the portfolio.

## Stack

React, Vite, JavaScript, CSS, Lucide icons, GitHub Actions and GitHub Pages.
